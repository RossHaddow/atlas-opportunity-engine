# Atlas Build 37 — Daily Executive Briefing

Status: COMPLETE

Build 37 turns Atlas from a collection of portfolio tools into a faster daily operating surface.

## What changed

- Version bumped to 1.6.0.
- Activates the Daily Executive Briefing at the top of the live dashboard.
- Shows the current portfolio headline, live tests, attention count, interventions, decision-ready tests, recorded revenue, and recorded profit.
- Adds a **What Needs You** queue for urgent/due work.
- Adds **Next 3 Moves** so Atlas limits the daily operating focus to the highest-priority actions.
- Briefing items open the relevant opportunity or Testing Workspace.
- Refreshes the briefing whenever portfolio data is reloaded after a user action.
- Fixes the Command Center attention-priority wiring to use the canonical `attention_level` generated by `nextActionState`.

## Product intent

Atlas should answer “What should I do next?” before the user has to inspect individual opportunities. Build 37 makes that question the first thing visible in the product.

## Verification

1. Run `npm run check`.
2. Confirm incomplete/overdue Testing work appears in Command Center attention.
3. Confirm `Next 3 Moves` never returns more than three items.
4. Load the dashboard and confirm the Daily Executive Briefing renders before the portfolio controls.
5. Confirm clicking briefing work opens the appropriate opportunity workspace.
