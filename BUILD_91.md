# Build 91 — Workspace Layout Foundation

Atlas now opens in a focused workspace view instead of presenting every module as one continuous dashboard.

- Command Center: executive briefing, next money moves, action queue.
- Opportunities: Radar, portfolio, active tests, opportunity records.
- Travel: full Travel workspace.
- Weird Things: dedicated child page at `/weird-things.html`.

The selected workspace is retained in the URL hash for shareable/reload-safe navigation.
